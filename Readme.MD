## Key Concepts
- `/` → Normal division
- `//` → Floor division
- `%` → Remainder
- `range(n)` → Generates values from `0` to `n-1`
- `*args` → Multiple positional arguments stored as a tuple
- `**kwargs` → Multiple keyword arguments stored as a dictionary
- `mutable` → Can be changed after creation
- `immutable` → Cannot be changed after creation
